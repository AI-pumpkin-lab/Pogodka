# Погодка: веб-версия 🎃🍄

Тыковка с грибочком в браузере. Ставится на айфон и Андроид как приложение, без App Store.

## Посмотреть прямо сейчас
Дважды кликни `index.html`, и он откроется в браузере. Погода уже работает.

## Выложить в интернет (бесплатно, GitHub Pages)
1. Зайди на github.com и зарегистрируйся, если аккаунта ещё нет.
2. Справа вверху нажми **+** → **New repository**.
   - **Repository name:** `pogodka`
   - **Public**
   - Нажми **Create repository**.
3. На странице нового репозитория нажми ссылку **uploading an existing file**.
4. Перетащи туда **всё содержимое** этой папки: `index.html`, `manifest.webmanifest`, `sw.js`, папку `icons`, README. Нажми **Commit changes**.
5. Открой **Settings → Pages**. В блоке **Branch** выбери `main` и `/ (root)`, нажми **Save**.
6. Подожди 1–2 минуты и обнови страницу. Наверху появится ссылка вида `https://ТВОЙНИК.github.io/pogodka/`. Это и есть твоё приложение 🎉

## Поставить на айфон
1. Открой ссылку в **Safari**.
2. Нажми **Поделиться** (квадрат со стрелкой) → **На экран «Домой»** → **Добавить**.
3. На рабочем столе появится тыковка, и приложение откроется на весь экран.

## Поставить на Андроид
Открой ссылку в Chrome, нажми ⋮ → **Добавить на главный экран** (или **Установить приложение**).

## Как обновлять
Поменяла что-то в `index.html`? Загрузи файл в репозиторий ещё раз (**Add file → Upload files**). Через минуту обновится у всех, кому ты скинула ссылку. Если на телефоне сразу не видно изменений, закрой приложение и открой снова.

## Что где в `index.html`
- `SCENES` — названия, цвета и фразы для 8 погод. Сюда удобно дописывать свои фразы.
- `pickScene` — правила, какая сцена когда показывается.
- `pumpkin` и `mushroom` — как нарисованы персонажи.
- `DRAW` — сами сцены с анимациями.
- `C` — палитра. Например, `boots` — цвет резиновых сапожек.
